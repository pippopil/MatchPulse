# MatchPulse — Аналитический парсер футбольных матчей в реальном времени

Локальное аналитическое приложение для мониторинга футбольных матчей (лайв и прематч) с поддержкой очных встреч H2H, графиками 15-минутных интервалов голов (**Recharts**), фильтрацией по процентам голов и мгновенным запуском в 1 клик.

**Работает на 100% без VPN на территории Российской Федерации.**

---

## ⚡ Запуск сразу одним файлом БЕЗ дополнительной установки чего-либо

Вам **не нужно** вручную устанавливать Node.js, не нужно открывать командную строку и не нужны права администратора. Проект уже поставляется полностью предварительно скомпилированным (`dist/` и автономный `server.js`).

### Как запустить:
1. Скачайте папку с приложением (например, нажав зеленую кнопку **Code** -> **Download ZIP** на GitHub и распаковав архив в удобное место).
2. Зайдите в папку и просто **дважды кликните по файлу**:
   👉 **`Запуск_MatchPulse.bat`** *(или `start_windows.bat`)*
3. **Готово!**
   - Если на компьютере уже есть Node.js — приложение стартует мгновенно (за 0.5 секунды).
   - Если на компьютере **вообще ничего не установлено** — скрипт один раз сам за 3–5 секунд загрузит официальный портативный модуль `node.exe` прямо в локальную папку `bin/` (без установки в реестр Windows и без прав администратора).
   - Приложение откроется как отдельное окно рабочего стола (в режиме приложения Microsoft Edge или в вашем основном браузере) по адресу **`http://localhost:3000`**.

> 💡 **Удобство**: Нажмите правой кнопкой мыши на `Запуск_MatchPulse.bat` → **«Отправить»** → **«Рабочий стол (создать ярлык)»**. Теперь MatchPulse запускается как обычная программа двойным кликом по иконке на рабочем столе!

## 🛠️ Архитектура портативного запуска

В папке приложения находятся:
- **`dist/`** — полностью собранный клиентский интерфейс (HTML5, Tailwind CSS, Recharts, React SPA).
- **`server.js`** — автономный веб-сервер и парсер Flashscore Ninja / Fonbet / LiveScore / ESPN без сторонних npm-зависимостей.
- **`Запуск_MatchPulse.bat`** — умный загрузчик и раннер для Windows 10 / 11.
- **`start_windows.bat`** — альтернативный батник для англоязычных систем.

## 📊 Основные аналитические функции

1. **Столбчатый график Recharts (интервалы 15 минут)**:
   - Наглядная гистограмма по 6 ключевым отрезкам каждого матча: `1-15'`, `16-30'`, `31-45+'`, `46-60'`, `61-75'`, `76-90+'`.
   - **Статистическая вероятность гола**: каждый столбец отображает математическую вероятность взятия ворот в заданный временной интервал.
   - **Размер выборки**: в шапке графика и подсказке явно указано количество матчей, взятых для расчета (последние 10 матчей хозяев + 10 матчей гостей + 4-6 очных встреч H2H, суммарно 20-25+ матчей).
   - Подсветка **пикового опасного интервала** (где забивается наибольший процент мячей).
   - 3 режима отображения:
     - *Вероятность гола (%)*;
     - *Сравнение команд (забитые %)*;
     - *Баланс забитых и пропущенных мячей*.

2. **Переключение между источниками данных**:
   - 🌐 **Все источники (390+ матчей / 150+ в лайве)** — объединенный поток со всех парсеров.
   - ⚡ **Flashscore Live (140+ матчей в эфире)** — детальный онлайн-поток всех текущих игр мира (включая молодежные турниры U19/U20, Африку, Азию, европейские региональные лиги и кубки).
   - 🔴 **Fonbet Линия** — линия букмекера с коэффициентами на исходы (1X2), тоталы и H2H.
   - 🌍 **LiveScore Global** — альтернативный глобальный стрим.
   - 🏆 **ESPN World** — табло топовых чемпионатов и еврокубков.

3. **Фильтры отбора матчей**:
   - Фильтр по статусу (Все / Только Лайв / Только Прематч).
   - Фильтр по минуте текущего матча (слайдер 0–90').
   - Порог вероятности **ТБ 2.5 (%)**.
   - Порог гола в **1-м тайме (%)**.
   - Порог опасного гола в **концовке 76-90+' (%)**.
   - Порог **«Обе забьют» (%)**.
   - Поиск по названию команды или турнира.

4. **Управление и экспорт**:
   - Большая кнопка **«Старт / Остановить»** для мониторинга в реальном времени.
   - Выбор интервала авто-обновления: 15 сек, 30 сек, 60 сек.
   - Всплывающие уведомления при забитых голах в лайве.
   - Кнопка **«Экспорт выборки в CSV»** для сохранения аналитической таблицы в Excel.
